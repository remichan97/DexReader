# Toast Component

Transient notifications. `Toast` wraps the Fluent 2 `Toast` / `ToastTitle` / `ToastBody` primitives; state lives in the global Zustand `toastStore`, and a single `ToastContainer` mounted in `App.tsx` renders whatever is in the store.

## Components

### Toast

A single toast: a status icon, a title, an optional message and a close button. Rendered by `ToastContainer`; you rarely use it directly.

### ToastContainer

Fixed-position wrapper that renders the active toasts. `App.tsx` mounts one instance (`position="bottom-right"`), so feature code never mounts its own.

### useToast (from `@renderer/stores`)

The hook is an alias of `useToastStore` in `src/renderer/src/stores/toastStore.ts`. It is **not** exported from this folder.

## Usage

```tsx
import { useToast } from '@renderer/stores'

function SaveButton() {
  const { show } = useToast()

  const handleSave = async () => {
    await save()
    show({
      variant: 'success',
      title: 'Changes saved',
      message: 'Your settings have been updated'
    })
  }

  return <Button onClick={handleSave}>Save</Button>
}
```

`ToastContainer` is wired up once, in `App.tsx`:

```tsx
const { toasts, dismiss } = useToast()

<ToastContainer toasts={toasts} onDismiss={dismiss} position="bottom-right" />
```

### Custom Duration

```tsx
// Auto-dismiss after 3 seconds
show({ variant: 'info', title: 'Quick message', duration: 3000 })

// Never auto-dismiss
show({
  variant: 'error',
  title: 'Critical error',
  message: 'Manual dismissal required',
  duration: 0
})
```

### Manual Dismissal

```tsx
const { show, dismiss, dismissAll } = useToast()

// show() returns the toast's ID
const toastId = show({ variant: 'loading', title: 'Processing...', duration: 0 })

dismiss(toastId) // dismiss one
dismissAll() // dismiss everything
```

## Toast Props

| Prop         | Type                                                       | Default      | Description                                     |
| ------------ | ---------------------------------------------------------- | ------------ | ----------------------------------------------- |
| `id`         | `string`                                                   | **required** | Unique identifier (generated by `show`)         |
| `variant`    | `'info' \| 'success' \| 'warning' \| 'error' \| 'loading'` | **required** | Toast type                                      |
| `title`      | `string`                                                   | **required** | Toast title                                     |
| `message`    | `string`                                                   | `undefined`  | Optional message                                |
| `duration`   | `number`                                                   | `5000`       | Auto-dismiss duration (ms), 0 to disable        |
| `onClose`    | `(id: string) => void`                                     | **required** | Close handler                                   |
| `className`  | `string`                                                   | `undefined`  | Class applied to the toast                      |
| `aria-label` | `string`                                                   | `undefined`  | Accessible label (defaults to "variant: title") |

## ToastContainer Props

| Prop        | Type                                                               | Default       | Description                  |
| ----------- | ------------------------------------------------------------------ | ------------- | ---------------------------- |
| `toasts`    | `ToastItem[]`                                                      | **required**  | Active toasts from the store |
| `onDismiss` | `(id: string) => void`                                             | **required**  | Called when a toast closes   |
| `position`  | `'top-right' \| 'top-center' \| 'bottom-right' \| 'bottom-center'` | `'top-right'` | Container position           |

The container renders nothing while there are no toasts.

## useToast Hook

Returns the toast store state and actions:

| Property     | Type                                       | Description                            |
| ------------ | ------------------------------------------ | -------------------------------------- |
| `show`       | `(toast: Omit<ToastItem, 'id'>) => string` | Show a new toast, returns the toast ID |
| `dismiss`    | `(id: string) => void`                     | Dismiss a specific toast               |
| `dismissAll` | `() => void`                               | Dismiss all toasts                     |
| `toasts`     | `ToastItem[]`                              | Array of active toasts                 |

## Variants

Each variant has a status icon in the title; the icon colour comes from the `--win-info`, `--win-success`, `--win-warning` and `--win-error` tokens in `tokens.css`.

| Variant   | Use for                                    | Icon                 |
| --------- | ------------------------------------------ | -------------------- |
| `info`    | Informational messages                     | Info circle          |
| `success` | Successful operations                      | Checkmark circle     |
| `warning` | Warnings and cautions                      | Warning triangle     |
| `error`   | Errors and failures                        | Dismiss circle       |
| `loading` | Work in progress (pair with `duration: 0`) | Small `ProgressRing` |

## Features

- **Auto-dismiss**: Defaults to 5000ms; set `duration: 0` to disable. The store owns the timer (and clears it when a toast is dismissed early).
- **Close button**: Every toast has a dismiss button labelled with the translated "close notification" string.
- **Stacking**: Several toasts can be shown at once; they stack vertically inside the container.
- **Size**: Each toast is 320px minimum and 400px maximum wide.
- **Click-through gaps**: The container ignores pointer events and each toast restores them, so the space around toasts doesn't block the page.

## Accessibility

- Each toast has `role="alert"` and `aria-live="assertive"`, and an `aria-label` of `"<variant>: <title>"` unless you pass one
- The container is `aria-live="polite"`
- The close button has a translated `aria-label`

## Styling

Fluent supplies the toast surface, border and shadow from the app theme. DexReader adds the status icon colours, the size caps and the close button through `makeStyles`; the only stylesheet is `Toast.css`, which positions the container (`.toast-container--*`).

## Examples

### Success and Failure

```tsx
const handleSubmit = async () => {
  try {
    await saveData()
    show({
      variant: 'success',
      title: 'Saved successfully',
      message: 'Your changes have been saved'
    })
  } catch (error) {
    show({ variant: 'error', title: 'Failed to save', message: error.message })
  }
}
```

### Loading, Then Result

```tsx
const handleDownload = async () => {
  const toastId = show({ variant: 'loading', title: 'Downloading...', duration: 0 })

  try {
    await download()
    dismiss(toastId)
    show({ variant: 'success', title: 'Download complete' })
  } catch (error) {
    dismiss(toastId)
    show({ variant: 'error', title: 'Download failed', message: error.message })
  }
}
```

## Best Practices

1. **Keep titles short** - One line preferred
2. **Be specific** - Clearly state what happened
3. **Use the right variant** - Match severity to variant
4. **Persistent errors** - Use `duration: 0` for errors the user must act on
5. **Avoid spam** - Don't show many toasts at once
